# Contributing to LearnHarness Personal

This is an independent fork. Open fork-specific issues and pull requests here, with synthetic examples and no study data or credentials. Contributions are accepted under the existing AGPL-3.0-only license; preserve third-party notices and document significant changes.

Run `npm run typecheck`, `npm test`, `npm run lint` and `npm run build` before submitting. The Windows artifact workflow is manual until a native build has been reviewed. Changes to billing, automatic speech, migration or external services should state their user-visible behavior clearly.

Contributing upstream is a separate, optional action; this fork does not automatically submit changes to the original author.
